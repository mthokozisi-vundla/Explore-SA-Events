# Explore SA Events 🇿🇦

## About the Project

Explore SA Events is a website created as part of our group assessment. The purpose of the website is to help people discover events and activities taking place in South Africa.

The website provides information about events, introduces the project team, displays images in a gallery, and allows visitors to contact us through a contact form.

Our goal is to create a simple, attractive, and user-friendly website while applying the HTML, CSS, and JavaScript skills we have learned.

## Project Objectives

- Create a website with multiple connected pages.
- Use HTML5 to structure the website.
- Use CSS to improve the design and make the website responsive.
- Use JavaScript to add interactive features.
- Practise working as a team and managing a shared project using GitHub.
- Improve our coding, communication, and problem-solving skills.

## Website Pages

The website consists of the following pages:

1. **Home** – Introduces the website and helps visitors navigate to other sections.
2. **About Us** – Provides information about the project and the team.
3. **Events** – Displays information about events happening in South Africa.
4. **Gallery** – Showcases images related to events and activities.
5. **Contact Us** – Allows visitors to send a message through a contact form.

## Technologies Used

- **HTML5** – Used to create the structure and content of the website.
- **CSS3** – Used to style the website and support different screen sizes.
- **JavaScript** – Used to add interactive features and form validation.
- **GitHub** – Used to store the project files and collaborate as a team.

## Interactive Features

The website aims to include the following JavaScript features:

- A welcome message or interactive banner.
- An image slideshow in the gallery.
- Contact form validation with error messages.
- An interactive event feature, such as an event cost calculator.

Additional features may be included as development continues.

## How to View the Website

1. Clone or download this repository.
2. Open the project folder on your computer.
3. Open `index.html` in a web browser.
4. Use the navigation menu to explore the different pages.

A code editor such as Visual Studio Code can be used to view and edit the project files.

## Teamwork and Collaboration

This project is being developed by a group of five students. Each team member is responsible for assigned tasks and contributes to the completion of the website.

GitHub is used to manage our files, track changes, and collaborate on the project. Team members can work on separate branches and submit pull requests so that changes can be reviewed before being merged into the main project.
